# Security Policy

This document outlines the security policy for **LilawatTechBlog**.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by contacting the maintainers via email: **[security@mukeshlilawat.com](mailto:security@mukeshlilawat.com)**. Include the following information:

* Detailed description of the vulnerability
* Steps to reproduce the issue
* Impact and potential risks
* Any screenshots or logs if applicable

Do **not** create public issues for security vulnerabilities.

---

## Supported Versions

* The latest stable release of LilawatTechBlog is supported for security fixes.
* Older versions may not receive updates.

---

## Security Best Practices

* Always use strong passwords
* Keep dependencies up-to-date
* Use HTTPS for all API endpoints
* Regularly review user roles and permissions
* Regularly backup your database
