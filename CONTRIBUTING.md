# Contributing to LilawatTechBlog

Thank you for considering contributing to **LilawatTechBlog**! Your help is greatly appreciated. This guide explains how to contribute properly.

---

## How to Contribute

1. **Fork the repository**
2. **Clone your fork**

```bash
git clone https://github.com/mukeshlilawat1/lilawattechblog.git
```

3. **Create a new branch** for your feature or bugfix

```bash
git checkout -b feature/your-feature-name
```

4. **Make changes** in your branch
5. **Commit your changes**

```bash
git commit -m "Add meaningful commit message"
```

6. **Push your branch**

```bash
git push origin feature/your-feature-name
```

7. **Open a Pull Request** from your branch to the main repository

---

## Coding Guidelines

* Follow **Java and React best practices**
* Write clean, readable, and commented code
* Use meaningful variable and function names
* Follow the existing code style in the repo

---

## Reporting Issues

* Check if the issue already exists before creating a new one
* Provide clear steps to reproduce the issue
* Include screenshots if applicable

---

## Code Review

* Ensure all tests pass before submitting a PR
* PRs will be reviewed and merged by maintainers

Thank you for contributing and making **LilawatTechBlog** better!
